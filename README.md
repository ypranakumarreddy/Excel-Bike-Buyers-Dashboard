# Excel Bike Buyers Dashboard

This project demonstrates how to clean, analyze, and visualize data in Excel by building an interactive dashboard. It is ideal for beginners in data analytics and can be used as a portfolio project.

## Project Overview

- **Data Cleaning:** Removed duplicates, standardized values, and created age brackets.
- **Analysis:** Used pivot tables to explore relationships between demographics and bike purchases.
- **Visualization:** Built charts and an interactive dashboard with slicers for filtering.
- **Interactivity:** Users can filter by marital status, region, and education.

## How to Use

1. Download the `Full Excel Project.xlsx` file.
2. Open it in Microsoft Excel.
3. Explore the dashboard and use the slicers to filter the data.

## Skills Demonstrated

- Data cleaning and transformation in Excel
- Pivot tables and charts
- Dashboard design and interactivity
